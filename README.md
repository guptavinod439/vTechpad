# Simple Text Editor in Java

A lightweight text editor application built in Java, designed to provide basic text editing and file management functionalities. The project was developed as part of an academic submission under the guidance of **Prof. Ranjita Gaonkar** at **Pillai College of Engineering, New Panvel** (2017–2018).  

---

## ✨ Features

The editor supports all essential text editing operations, including:

- **File Operations**
  - Create a New File
  - Open an Existing File
  - Save and Save As
  - Page Setup
  - Print
  - Exit  

- **Edit Operations**
  - Cut, Copy, Paste, Delete
  - Find and Find Next
  - Replace Text
  - Go to Line
  - Select All  

- **Format Options**
  - Word Wrap
  - Change Fonts  

- **Help Menu**
  - About  

---

## 🛠️ Tech Stack

- **Language**: Java  
- **GUI Framework**: Swing / AWT  
- **Development Tools**: Any Java IDE (Eclipse, IntelliJ IDEA, or NetBeans)  

---

## 🚀 Getting Started

### Prerequisites
- Install [Java JDK 8 or higher](https://www.oracle.com/java/technologies/javase-downloads.html).
- Install any Java IDE (Eclipse, IntelliJ IDEA, NetBeans) or use command line.

### Steps to Run
1. Download the jar file and double click to run it.
---

## 📖 Usage

- Navigate through the **File, Edit, Format, and Help menus** for various operations.  
- Use **Page Setup & Print** for preparing documents.  
- Change **Font & Word Wrap** to format text according to preference.
